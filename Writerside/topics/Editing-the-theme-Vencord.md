# Editing the theme (Vencord)

How you edit %chillax% depends on how you installed it.
If you haven't installed it yet, follow the
<a href="Installation-guide.md#vencord">Vencord installation guide</a> first.

## Installed via QuickCSS (recommended)

If you pasted the theme into QuickCSS, go to
<ui-path>Settings > Vencord > Themes > Edit QuickCSS</ui-path>.
This opens the built-in [Monaco](https://microsoft.github.io/monaco-editor/) code editor,
and changes apply as you type.

> If QuickCSS is blank, you installed the theme as a file. Use the section below instead.

{style="tip"}

## Installed by downloading the file

If you downloaded **chillax.theme.css** (for example from the
<a href="https://betterdiscord.app/theme/Chillax">BetterDiscord website</a>) and enabled it as a theme,
go to <ui-path>Settings > Vencord > Themes > Open Themes Folder</ui-path>
and open **chillax.theme.css** with any text editor
(*for example <a href="https://code.visualstudio.com/">VSCode</a> or Notepad*).

> Save the file for your changes to take effect.
> In most editors, press `ctrl + s`.
